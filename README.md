# NEXORA ERP

NEXORA ERP is a responsive front-end demo for managing everyday business operations. It includes dashboards and pages for employees, customers, products, inventory, sales, invoices, finance, reports, notifications, profile settings, and role-based access.

## Getting started

Open `index.html` in a modern web browser, then sign in with one of the demo accounts below.

| Role | Email | Password |
| --- | --- | --- |
| Admin | `admin@nexora.com` | `admin@123` |
| Manager | `manager@nexora.com` | `manager@123` |
| Employee | `employee@nexora.com` | `employee@123` |

## Features

- Role-based page access for Admin, Manager, and Employee accounts
- Business dashboard with role-specific information
- Management pages for employees, customers, products, inventory, sales, and invoices
- Finance, reports, notifications, and profile pages
- Responsive sidebar navigation
- Light and dark theme preference

## Theme preference

The theme can be changed from **Settings**. The selected mode is saved in the browser, so dark mode remains active after refreshing the page or moving to another workspace page.
